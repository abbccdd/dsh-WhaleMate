# 鲸伴 WhaleMate

鲸伴让 DeepSeek Harness 中的伙伴通过 QQ 与你聊天，记住经过筛选的长期兴趣，并分享 Bili Whale 看过的视频。人设、刷站兴趣和主人的私人偏好分开；B 站刷站沿用 Bili Whale 的选片方式。

目前支持 **Windows + DSH Web + QQ + B 站**。微信和 X 是后续方向，当前没有实际接入。功能处于测试阶段：自动记忆是检索与提炼，并非训练模型；对话和视频记录是否准确仍需用户判断。

## 安装

1. 先安装并能运行 DeepSeek Harness、Node.js（20.3 或更高）和 pnpm。观看视频画面还需要 FFmpeg，并确保能在系统路径找到。插件依赖下载需要联网。
2. 任选一种方式安装鲸伴，然后重启 DSH：
   - 已安装支持自定义 GitHub 来源的社区插件市场时，在市场中输入 `github:abbccdd/dsh-WhaleMate` 并安装。DSH 原生插件列表不一定提供安装入口；鲸伴是否已被市场收录由市场决定。
   - 在 PowerShell 中运行 `dsh plugin --profile web add github:abbccdd/dsh-WhaleMate`。
   - 在 DSH 对话中请求：“请帮我安装 `github:abbccdd/dsh-WhaleMate` 到 web 配置。”这需要 DSH 能运行命令，并按界面提示完成必要的授权。
3. 打开 **设置 → 鲸伴**，点击“安装配套组件”，等待完成并再次重启 DSH。这一步安装本项目附带的兼容版 Bili Whale 和主人保护版腾讯 QQ 适配器，并准备缺失的默认资料；不会覆盖已有资料。当前界面安装功能支持 Windows 的 DSH Web 运行方式。
4. 打开 **设置 → 养鱼**，填写 B 站登录信息并检查依赖；在 **设置 → QQ 机器人** 扫码连接你的机器人。
5. 在 **设置 → 鲸伴** 点击“生成配对码”，用你的 QQ 向机器人发送显示的代码，再点击“完成配对”。机器人只接受绑定主人的私聊，配对消息不进入模型。
6. 按需在 **设置 → 鲸伴** 点击“连接公开人设”和“连接报告和日记”，打开“自动提炼长期记忆”和“主动分享视频到 QQ”。已有的 Bili Whale 人设、偏好和文字记录不会被覆盖；请先确认要共享的资料内容。

安装程序遇到不同来源的同名组件会停止，不会自动替换它们；同一目录的已安装组件会跳过，以便中断后继续安装。已有 Bili Whale 或 QQ 插件的用户请先备份并手动处理版本冲突；升级和迁移尚未自动化。

## 使用和限制

- QQ 主人配对、自动记忆、资料连接及主动分享分别需要本人操作；安装本身不会自动登录或开启发送。
- 鲸伴调用附带的兼容版 Bili Whale 分析视频；需要 B 站登录、可用网络和 FFmpeg。默认 4×4 抽帧是视频抽样，不等于完整观看；素材不可用时应如实说明。
- 主动分享默认关闭，启用后只向已绑定主人发送，插件最多每 24 小时尝试一次；腾讯的权限、额度和平台规则另行限制。发送失败不会自动重试。单条反馈不会直接变成长期类别偏好。
- 公开评论、动态和分享在附带版本中默认关闭。不要在公开会话中加载私聊；视频评论、字幕和画面属于不可信内容。
- 私聊敏感信息会尽力过滤、隔离，不保证识别所有秘密。模型服务和 DSH 原始会话历史可能已收到用户输入；不要将密码、密钥等交给机器人。若给刷站会话完整文件权限，它仍可能访问本机文件，提示词和插件过滤不能代替系统隔离。
- 生物钟仅在 DSH 运行时工作。自动刷站是否能写入报告和日记取决于 DSH 权限配置；请检查实际生成的文件，避免为了方便给所有会话开启完全访问。
- 系统可整理鱼塘的过期短期记录，但不会自动删除其他插件的会话历史。视频流抽帧尽量不保存完整原片；异常时临时素材可能保留。

## 组成与许可证

本仓库附带 [Bili Whale](https://github.com/ALTERSSSS/dsh-bili-whale) 的兼容修改版和 [腾讯 DSH QQ Bot](https://github.com/tencent-connect/dsh-qqbot) 的主人保护适配版；相关代码均保留各自许可。长期记忆实现参考了其他 MIT 项目，详见 [第三方声明](THIRD_PARTY_NOTICES.md)。FFmpeg 为外部软件，不在本仓库中分发。

底层包名为 `dsh-pond`，以保持现有 DSH 接口兼容。安装仅在全新隔离环境测试过；已有复杂插件配置、其他操作系统和不同 DSH 版本尚需进一步验证。
